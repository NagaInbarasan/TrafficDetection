Slide 2: Computer Vision Pipeline
Title: Computer Vision Pipeline
Subtitle: Real-time frame processing from actual video footage
- OpenCV VideoCapture: Efficient frame-by-frame extraction
- YOLO (yolo26s.pt): High-accuracy pretrained vehicle detection
- ByteTrack: Persistent multi-object tracking IDs
- Real-time AI annotation directly on the live frames

Slide 3: Bidirectional Geometric Counting
Title: Bidirectional Geometric Counting
Subtitle: Accurate vehicle counting and direction assignment
- Configurable Counting Line: Adjustable via UI slider
- Vector Math (Cross Product): Determines line crossings geometrically
- Direction Tracking: Distinguishes Forward vs Reverse flow
- Duplicate Prevention: Prevents multiple counts for slow vehicles

Slide 4: Empirical Time-Series Forecasting
Title: Empirical Time-Series Forecasting
Subtitle: Forecasting based on actual observed video data
- Time Windows: Aggregating crossings every 10 seconds
- Algorithm: Holt's Damped Linear Trend
- Damping Factor (φ = 0.85): Smooths predictions over time
- Horizons: Predicts 1-min, 5-min, and 10-min future flow

Slide 5: System Architecture
Title: System Architecture
Subtitle: Modern, modular, and performant backend
- Python & Flask: Asynchronous video processing and REST APIs
- SQLite Database: Isolated video sessions and historical metrics
- Hardware Acceleration: PyTorch with CUDA for RTX GPUs
- Frontend Integration: Dynamic JS fetching and Chart.js rendering

Slide 6: Dashboard & UI Features
